# SYTYCDfNIRS

An onboarding tutorial series on fNIRS analysis in Python, for newcomers with EEG experience. It goes from what fNIRS measures to a group-level statistical result on open data, and it is published as a Jupyter Book.

The book is published at <https://ramdam17.github.io/fnirs-tutorials/>. The modules and their reading order are added there as they are written.
